# 卓盛工具箱

面向 Windows 10/11 x64 的内部维护工具合集，提供内置系统信息与设备查询。

## 安装与启动

1. 运行发行目录内的“卓盛工具箱-安装-v版本号.exe”，允许管理员授权，点击“安装”。
2. 首次安装可在“安装位置”输入路径或点击“浏览”，例如 `D:\卓盛工具箱`；默认仍为 `C:\Program Files\InternalToolbox`。请选择已有父目录下的独立空文件夹。安装器会检查目录权限，不修改上级目录权限。安装完成后，从开始菜单打开“卓盛工具箱”。
3. 升级自动沿用原位置。已安装版本若需要换盘，请先卸载，再选择新位置重新安装；本轮不自动搬移已有安装。
4. 每次启动均需要管理员权限，访问密码为 `[本机访问口令，公开版省略]`。
5. 安装器检测 Microsoft Edge WebView2 Runtime；缺少时调用微软已签名的安装引导程序配置，需要联网。官方地址：https://developer.microsoft.com/microsoft-edge/webview2/ 。

## 使用

登录后首先显示系统信息。左侧按常用、网络、磁盘、重装维护及系统设置分类，并保留软件合集入口。顶部搜索名称或用途；单击工具查看右侧说明，双击工具直接打开，也可选中卡片后按 Enter 或点击“打开工具”。启动中的重复操作会被合并或拦截。

“常用工具”由你自己选择：点击工具卡片右上角的空心爱心，即可标记为常用工具；点亮后会出现在“常用工具”页，再次点击即可取消。首次使用不预设常用工具，可点击“去选择常用工具”进入全部工具。选择保存在本机，锁定、重新登录或关闭重开后仍会保留；点击爱心不会打开工具。

Geek 软件卸载工具可在“全部工具”搜索卸载查找，也可以点击爱心加入常用；“重装维护 → 驱动与修复”提供系统必备运行库修复。按本次要求，“系统激活工具”和“关杀毒更新工具”已移除；其他独立工具入口保留。

工具打不开或怀疑文件不齐时，进入“使用说明”，点击“检查工具文件”。软件会在后台核对随附文件，区分文件完整、缺失、已变化和无法读取，默认只列出需要处理的项目，也可展开全部结果。检查不会运行维护工具；锁定会取消当前检查并清除结果。文件缺失或变化时，请重新安装完整工具箱，可通过“前往软件更新”检查新版。文件完整不代表第三方工具的维护效果或完整安全扫描通过。

搜索支持用空格分隔多个关键词。各工具分类分别保留搜索词与选中项；切换页面后，软件合集的分类、搜索词，以及系统信息的当前标签和设备筛选也会保留。锁定后清除本次登录的浏览条件和任务提示，重新登录后从系统信息开始；锁定前尚未返回的任务提示不会覆盖新会话。

点击页面标题前的按钮可以隐藏或恢复左侧栏，工具箱会记住选择；恢复按钮始终保留在顶部。每个工具使用原生图标，没有可用资源的工具使用固定生成的彩色图标。

“重装维护”的“系统重装”分组提供两个工具：天猫一键重装（原文件名为天喵，工具密码 `1788`）和技术员一键重装（工具密码 `vip0`）。工具密码以醒目的独立区域显示，并提供复制按钮；密码仅用于对应的第三方工具，与工具箱登录密码不同。技术员原程序已随软件打包，启动前同样校验文件。

工具箱启动时在后台读取 Windows 记录的安装时间，结果仅在系统信息页显示。安装时间在过去 72 小时内且本次安装尚未处理提醒时，提示使用驱动总裁检测驱动。勾选确认后才打开内置驱动总裁，具体检测、选择和安装仍在驱动总裁内完成。选择“暂不检查”或成功打开后，本次系统安装不再提示；关闭后重新打开软件也保留记录。提示记录在本机 `ProgramData\InternalToolbox\driver-reminder.txt`，不随工具箱升级重置。

关闭工具箱会结束本次由它打开的工具及其子进程；工具箱被强制结束时同样生效。请等待工具操作完成后再退出。更新安装器独立运行，工具箱退出后继续完成安装。已经写入的系统设置、已安装的驱动和第三方工具另行注册的系统服务不会因此撤销。

安装时间无法读取或晚于当前时间时不会触发自动提醒，手动驱动入口仍可用。Windows 升级、镜像部署可能改变安装时间，因此此提醒只表示建议检查，不能证明缺少驱动。重装或驱动安装效果尚需在目标电脑实际验收。

工具箱每次启动时，先统一显示一次使用提示，确认后进入密码页。同一次运行中，锁定后重新登录也不重复提示。点击“打开工具”、双击卡片或按 Enter 都会先在后台校验文件完整性，校验通过后直接启动原工具，不再逐项弹出确认。Windows 和原工具自身的确认仍按其原有流程显示。工具箱显示“已启动”仅代表成功打开进程，不代表设置、修复或数据恢复已经完成。

打开过的工具会在卡片和详情中显示运行状态：“正在打开”表示正在校验或启动；“运行中”表示该工具或其子进程仍在运行；“已退出”表示这些进程均已结束；“启动失败”会同时显示具体原因，可处理后重新打开。状态约每秒刷新，切换分类、重新加载界面和锁定后重新登录会恢复当前状态。尚未打开的工具不显示状态；关闭并重新启动工具箱后重新记录。运行中或已退出都不代表维护操作成功，结果仍以原工具提示为准。

右上角提供浅色、深色和跟随系统模式，主题偏好保存在用户目录。界面提供卡片进入、悬停反馈、详情切换与弹窗过渡；系统启用减少动画时会降低动效。

## 软件合集

左侧“软件合集”将《工具大合集.html》和装机必备软件库的条目合并在软件内，支持分类浏览和按名称、别名、用途搜索。目录随软件附带，离线也可浏览；访问网站和下载时需要联网。

软件合集首次进入时才加载目录，启动软件和查看本机信息时无需预先加载。再次进入时复用已加载的目录；搜索使用预先整理的索引，输入时减少重复计算。

每张卡片显示简介、分类、来源和入口域名。点击“访问网站”“下载文件”或“网盘下载”会在系统浏览器打开对应地址，再按网页提示操作；工具箱不会自动安装下载的软件。同一软件存在多个来源时，可以展开“其他入口”选择。网站入口优先显示，网盘分享会单独标明。

历史显卡驱动集中放在“历史显卡驱动”，请在下载页面核对显卡型号和操作系统。合集不把来源里的“稳定、推荐”等描述当成适配结论。无法打开时会提示失败，可重试或选择其他入口；第三方链接的后续可用性取决于提供方。

## 系统信息

左侧第一项“系统信息”在软件内展示本机查询结果，支持深浅主题、刷新、复制当前信息和复制单个设备信息。

本次开机首次使用工具箱时自动采集一次，之后切页、关闭重开、锁定重登都复用本机保存的结果。电脑再次启动后首次使用时重新采集，不增加开机自启动或后台常驻。点击“刷新信息”可主动更新。页面标注采集时间：磁盘可用空间、IP 地址、设备连接状态均为快照；显卡温度和占用率仍按需查询。

缓存位于当前用户的 `LocalAppData\InternalToolbox\Cache`，只在本机保存。缓存损坏或格式变化会重新采集；无法可靠识别本次系统启动时只在本次程序运行中复用，关闭重开会保守地重新采集。刷新失败会保留上次结果并显示提示。

硬件概览采用独立纵向排列，CPU、主板等较短卡片不会被内存、显卡的长内容拉高；多条内存、多显卡和多个硬盘逐项保留。

- **硬件概览**：分别列出 CPU、每条内存、主板、所有显卡、物理磁盘和网络适配器，不合并多设备实例。
- **BIOS 信息**：查看版本、日期、启动模式、安全启动及 Windows 报告的虚拟化状态。XMP / EXPO、风扇、启动顺序等厂商设置仍需进入 BIOS 查看。
- **磁盘分区**：按硬盘展示分区，保留没有盘符的 EFI / 恢复分区。分区容量、卷容量、文件系统和卷剩余空间分别展示；卷剩余空间不等于硬盘未分配空间。Storage 接口未提供分区时自动使用兼容查询。
- **机器码查询**：查看 CPU ID、系统 UUID、整机 / BIOS / 主板 / 硬盘 / 内存序列号、内存料号、网卡 MAC / IP 和 DHCPv6 DUID。字段缺失时标注“未提供”，不生成替代机器码。CPU ID 不保证独立唯一；内存料号不是生产时间。
- **显卡查询**：通用信息覆盖 Windows 识别的所有适配器；点击“查询显卡详情”调用现有 NVIDIA 驱动组件，查询 UUID、序列号、显存、温度与使用率快照。AMD / Intel 使用通用信息，不支持的字段明确提示。WMI 显存参考值会单独标注来源与准确性限制。
- **全部设备**：列出 Windows PnP 返回的设备，可按设备名称、类别或标识筛选，展开查看驱动与设备标识。

查询只读，不执行原 BAT 的终止 WMI 命令，不修改 BIOS、分区、硬件标识或设备配置，也不上传查询结果。刷新失败后保留的旧结果会明确标记。锁定或关闭软件会取消进行中的查询。

## 重要工具

- **Win10 优化系统**：系统设置分类，点击打开即执行所提供原脚本。会调整电源、取消自动睡眠和唤醒密码要求、关闭防火墙与 Defender 相关设置、禁用系统更新及处理升级助手，最后重启资源管理器。保存工作并记录原状态，无自动备份或撤销；未验证 Windows 11 兼容性。
- **HEU KMS Activator 63.3.4**：重装维护分类，内置用户提供的原程序，根据已有合法授权使用；启动不代表激活成功。
- **ACE 虚拟化环境检测修复**：系统设置分类，使用新的脚本封装，随安装包内置。保留 DMA、CPU 虚拟化、Hypervisor、VBS 四项检测，三种修复及 BIOS/UEFI 提示；默认只检测，修复由用户点击执行。修复可能影响虚拟机、Docker、WSL、Windows Hello 及系统保护；不自动重启，脚本退出不代表修复已生效。真实修复及重启流程尚未实测，详见工具内说明。
- **关闭 UAC 提示**：导入原 `.reg` 文件，写入 `EnableLUA=0`、`FilterAdministratorToken=0`。需要在 Windows 注册表编辑器里再次确认，通常重启后生效。此操作会降低 UAC 相关保护；工具箱运行本身无需关闭 UAC。
- **浏览器配置与推广清理**：根据用户要求完整封装原 BAT，保留全部原行为。包括浏览器配置、收藏夹以及 `D:\Backup\Favorites` 等路径删除；深度模式还清除程序和注册表，PE 模式保留原限制。没有自动备份、恢复或撤销，执行前手动备份。原脚本的已知问题详见源码目录中的审查报告。
- **重装与磁盘管理**：核对目标磁盘，提前备份；数据恢复时避免向原盘写入。天猫工具的原文件名标注密码 `1788`，技术员工具原文件名标注密码 `vip0`。
- **SMB 连接测试**：网络分类中打开，输入 NAS 地址、端口与可选共享名。端口通、SMB 协商成功和共享目录可读是不同结果；未连接真实 NAS 的部分仍需实际核验。
- **Windows 更新设置工具**：针对系统更新，和本工具箱的自动更新相互独立。

## 更新与故障

登录后检查工具箱更新。已配置服务器且有新版时，可查看发行说明、下载、校验，并选择安装。安装前关闭工具箱打开的工具；安装完成后重新打开。

更新地址已配置到官网。若维护人员尚未发布正式签名清单，检查会失败，现有工具仍可使用。完整在线升级需要经过旧版实际安装、升级与重启验收。

工具缺失或完整性校验失败时，重新安装正式包，不要手动更换同名文件。启动失败时查看工具提示；日志目录可在“使用说明”页面打开，日志不记录访问密码。

卸载入口在 Windows 的“已安装的应用”中。卸载只移除工具箱文件，不撤销第三方工具对系统的修改；个人主题设置与日志保留。

共享密码仅为内部访问门槛，不能防止软件被复制或内置工具被单独提取。文件名及版本信息不能证明第三方程序内部行为，具体说明已逐项标注。

## 常见操作问题

- 双击没有打开：先确认是否已有启动任务，查看屏幕提示；也可使用右侧“打开工具”按钮。
- 图标无法显示：会自动使用用途图标，不影响原工具的启动。
- 密码复制失败：选中密码文字后按 Ctrl+C；工具密码与工具箱登录密码不同。
- 查询后更换设备或网络：点击“刷新信息”，确认页面采集时间已更新。
- 工具缺失或校验失败：重新安装可信安装包，不要用其他来源的同名文件覆盖。
- 旧版升级：显示名称改为卓盛工具箱，仍沿用原安装记录和目录；开始菜单中的旧版自有快捷方式会更新为新名称。
