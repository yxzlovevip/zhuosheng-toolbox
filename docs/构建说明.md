# 构建与验证

本地 SDK 位于 `.build/dotnet`，通过微软官方 .NET 10 发布元数据下载，并核对 SHA-512；不修改全局 SDK。依赖由 `frontend/pnpm-lock.yaml` 和项目 NuGet 引用固定。

准备 Node、pnpm 和 .NET 10 SDK 后：

```powershell
pnpm --dir frontend install --frozen-lockfile
./.build/dotnet/dotnet.exe run --project tests/Toolbox.Tests
./.build/dotnet/dotnet.exe run --project tests/Toolbox.SetupTests
./.build/dotnet/dotnet.exe run --project tests/Toolbox.HostTests -- 1.3.10
./.build/dotnet/dotnet.exe run --project tests/Toolbox.ProcessTests
./tests/Toolbox.ShutdownWebTests/test.ps1
./.build/dotnet/dotnet.exe run --project tests/Toolbox.SystemInfoTests -- --live
./.build/dotnet/dotnet.exe run --project tests/Toolbox.SystemInfoWebTests
pnpm --dir frontend build
pnpm --dir frontend exec playwright test
./scripts/build.ps1
```

前端测试默认使用本机 Edge，通过专用本地测试服务替代宿主消息。不会运行真实工具，也不会执行浏览器清理。宿主控制器测试与 Windows 实机安装应分别验证。

运行状态测试使用只等待的测试程序及其子进程，验证每项工具的状态隔离、父进程退出后的子进程跟踪、失败重试，以及实际 WebView2 中的状态刷新、界面重载恢复和关闭清理，不执行真实维护工具。

安装器通过 Windows .NET Framework 编译器构建，压缩资源内置在 EXE，安装过程先校验资源，再在受保护目录中展开。保留上一版本到 `.previous`，安装前发现程序文件被占用就停止。

1.4.3 起工具全量内置包使用 Stored ZIP + LZMA2 固实压缩，固定官方 7zr 26.05（public domain），由 `scripts/Get-PackageCompressor.ps1` 下载并核对 SHA-256。构建将解压器内置，无需用户另装 7-Zip。安装器先核对压缩包与解压器，再仅通过标准输出解出固定 ZIP，核对长度与 SHA-256 后交给原安装引擎；临时文件在安装注册提交前清理，清理失败仍触发原安装事务回滚。约需 7 GB 可用空间，安装后的工具体积不因安装包压缩而改变。全部工具无需额外下载；首次安装的机器若缺少 WebView2，沿用原有联网运行库引导，不包含独立 WebView2 离线运行库。

压缩回归验证：先运行 `scripts/Get-PackageCompressor.ps1`，再运行 `.build/dotnet/dotnet.exe run --project tests/Toolbox.SolidPayloadTests`。完整新包验证可运行 `.build/dotnet/dotnet.exe run --project tests/Toolbox.PackageTests -- dist/卓盛工具箱-安装-v1.4.3.exe`；追加旧版 ZIP 安装包路径则同时验证隔离覆盖升级（不修改用户当前安装记录）。

1.4.4 起仍使用相同的 Stored ZIP + LZMA2 全量离线载荷，安装改为管道流式展开：校验压缩资源与内置解压器后，直接将标准输出中的 ZIP 文件展开到 `.stage-*`，同时计算整个 ZIP 的 SHA-256 并检查输出长度。逐项验证本地文件记录、中央目录、重复路径、链接、总展开大小和结束记录；长度、哈希和解压器退出码全部通过后才替换旧版。取消约 3 GB 的中间 ZIP 落盘及重复读取，当前包约需 4 GB 可用空间（程序按实际载荷计算）。解压文字显示完成百分比；原有配置保留、`.previous` 备份、目录锁重试和事务回滚继续生效。构建拒绝超出 ZIP32 大小或条目上限的包，不支持数据描述符、加密、Deflate 或 ZIP64 的流式内包；原有普通 ZIP 安装接口仍保留。

Windows .NET Framework 实际引擎覆盖验证：`tests/Toolbox.SolidPayloadTests/framework-package.ps1 -Installer dist/卓盛工具箱-安装-v1.4.4.exe -Previous dist/卓盛工具箱-安装-v1.4.3.exe`。该验证在独立受保护目录中调用真实安装器引擎，检查文件哈希、配置保留和备份，不注册安装记录或改动现有安装。

原 WPF 界面已被 React + WebView2 主界面替换。原界面测试保留为历史回归参考，不代表新版 WebView2 主界面已经验证。
