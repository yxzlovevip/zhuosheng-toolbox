# 界面与使用体验改进完成记录

2026 年 10 月 22 日，已根据《问题.docx》和已批准的改进计划完成 12 项修改。产品显示名称采用卓盛工具箱，源码版本为 1.3.0。正式安装包与线上更新由“强化色彩主题并接入自动更新”聊天统一生成和发布，本记录不表示已发布。

## 已完成的改进

| 原问题 | 已实现的行为 |
| --- | --- |
| 重装入口重复 | 合并为重装维护，分为系统重装、驱动与修复、激活与部署，原工具保留 |
| 缺少软件图标 | 27 个工具均有图标，其中 18 个提取原生图标，9 个生成用途图标，卡片与详情一致 |
| 硬件卡片大块留白 | 采用两列独立纵向排列；CPU、主板、内存、显卡、磁盘按内容确定高度，窄窗口单列 |
| 安装时间跨页重复 | 从公共工具列表移除，只在系统信息展示 |
| 密码难找 | 工具密码单独高亮并支持复制；复制动作不会触发打开工具 |
| 产品名称生硬 | 界面、登录页、原生窗口、安装与卸载显示统一为卓盛工具箱 |
| 说明过少 | 全局帮助扩充到 12 节，工具详情增加结果核对与打不开时的处理 |
| 系统信息位置太低 | 位于导航首位，登录后默认显示 |
| 反复读取系统信息 | 保存本次系统启动的快照；切页、锁定重登、关闭重开复用；支持手动刷新与缓存损坏恢复 |
| 缺少双击打开 | 单击选中查看说明，双击或 Enter 打开；同一工具的连续启动受保护 |
| 左栏不能隐藏 | 顶部按钮收起与展开侧栏，本机记住偏好，恢复入口始终保留 |
| 散列值占用界面 | 删除可见散列行和复制校验值按钮，后台文件及更新校验保留 |

保留了并行聊天接入的蓝紫青绿主题、自动更新、软件合集和新增维护工具，没有替换它们的功能。

## 兼容与验收边界

保留 CZToolbox 主程序名、InternalToolbox 安装标识、卸载注册键和原安装目录识别，避免改名形成另一份安装。安装登记成功后，只清理目标确认为本工具箱的旧开始菜单快捷方式；登记失败时恢复旧内容。

快照是采集时的信息，磁盘空间、IP 地址、设备状态和温度不表示实时监控。无法可靠读取启动标识时，只在当前运行中复用并在下次打开时重新采集；缓存文件不能写入时仍能正常显示查询结果。

实际机器重启、快速启动、休眠恢复、Windows 显示设置 125% 与 150%、完整安装登记及升级退出重启流程，仍需分别验收。启动标识变化的自动失效已通过隔离测试，不能替代真实重启验收。

本轮复用当前非 Git 工作目录，修改前源码已备份。沿用推荐名称和既有安装标识是本轮实现决定；未进行商标排查或迁移既有安装标识。界面验证使用项目已有 Playwright 与 Edge 流程。
