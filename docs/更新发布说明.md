# 工具箱更新发布

## 当前状态

2026-10-24 已发布 2.0.0，服务器签名更新清单已切换，全部 39 项工具保留。正式安装包、公开地址和验收范围见《线上发布-v2.0.0-2026-10-24》及 `dist/卓盛工具箱-v2.0.0-发布验证.json`。

2.0.0 新增用途搜索别名、下载入口来源与核对状态，以及工具运行时下载更新和安装前需关闭工具清单。已完成 1.4.4 → 2.0.0 独立目录安装器引擎升级验证；现有扫描告警及未覆盖的外网整包下载、Windows 全新安装流程如实保留在发布记录中。

完整保留全部工具和 LZMA2 离线压缩，改为边解压、边校验、边写入暂存目录，不再生成约 3 GB 的中间 ZIP。当前包安装时约需 4 GB 可用空间，并显示解压百分比；完整校验通过后才替换旧版，继续保留配置、旧版本备份和失败回滚。

线上版本以服务器公开的签名更新清单为准；本地候选版本不代表线上发布状态。覆盖安装时仍最多等待 15 秒处理暂时的目录占用，并记录安装日志。

客户端每次登录后自动检查一次，保持登录时每 6 小时检查一次，也可手动检查。发现新版会显示更新提醒；下载期间显示进度，支持取消与重试，校验完成后由用户点击“安装并重启”。更新地址为 `https://zskj.top/cz-updates/latest.json`，使用 HTTPS、RSA 签名及大小和 SHA-256 校验。检查失败会明确显示失败，不会误报已是最新版，现有工具仍可使用。

## 配置

当前地址保存在 `assets/update-settings.json` 的 `ManifestUrl`。已安装的软件可由管理员修改“所选安装目录\app\update-settings.json”。升级会读取 Windows 安装记录并沿用原安装位置，同时保留更新配置。

清单与 EXE 必须位于同一 HTTPS 主机及端口。不要使用 HTTP、需要登录的链接、网盘中转或跳转链接。没有更新、检查失败、尚未配置是三个不同状态。

## 发布新版

1. 修改版本号、源码和说明，执行测试并构建新版安装 EXE。
2. 使用项目根目录的签名脚本，参数为新版版本、安装包路径、HTTPS 目录地址与更新说明：

```powershell
./scripts/New-UpdateRelease.ps1 -Version 1.3.0 -InstallerPath ./dist/卓盛工具箱-安装-v1.3.0.exe -Notes '版本变更说明'
```

默认输出使用已有 `zskj.top/cz-updates/releases/版本号/`。先上传脚本生成的版本目录，核对公网文件大小、SHA-256 和清单签名，最后原子替换根 `latest.json`。不要覆盖已发布版本目录；后续改动必须提高版本号。

3. 运行 `tests/Toolbox.UpdateTests` 核对签名、下载和真实旧版包的隔离升级；发布后加 `--public` 验证公网。`tests/Toolbox.UpdateWebTests` 验证原生宿主的登录后自动检查。完整的 Windows 安装器退出等待、安装登记及重启仍需用已安装旧版单独验收，隔离安装引擎测试不等同于这一验收。

## 密钥

公钥在 `assets/update-public.pem`，编译时内置。私钥在本项目 `.private/update-private.pem`，不进入安装包、网站或工具目录。务必单独备份，不要随工具合集分发整个源码目录。已有客户端发布后不能随意换公钥，否则旧客户端无法验证新清单。

更新清单签名不是 Windows 软件发行者证书；当前 EXE 没有购买或使用 Authenticode 代码签名证书，Windows 可能显示未知发行者。
