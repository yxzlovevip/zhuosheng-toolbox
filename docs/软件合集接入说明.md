# 软件合集接入说明

2026-10-22，用户确认在现有工具箱中合并两个来源，左侧入口命名为“软件合集”。

## 内容与行为

- 《工具大合集.html》102 个条目，装机必备软件库 242 个链接条目。
- 去除原网站自身“新版 UI”导航后，按明确同名和别名归并为 222 项、17 个分类、307 个入口。
- 不同产品和地区版本保持区分，例如 Riot Client 与国服无畏契约、Steam 与蒸汽平台、三角洲国服与国际服。
- 页面提供分类、名称/别名/用途搜索、空结果提示、入口域名和来源；同一软件的其他入口可展开。
- 目录内置、离线可读。点击入口通过宿主交给系统浏览器，不在工具箱中下载或执行安装文件。
- 下载入口必须来自内置目录；宿主只接受软件 ID 与入口 ID，拒绝未登录、未知 ID 和调用者自行传入的 URL。
- 两份来源仅按数据解析，未执行其脚本；没有把其页面或第三方脚本嵌入软件。

## 纠错与来源边界

原始来源记录与 SHA-256 保存在 `assets/software-collection.json`。导入器 `scripts/import-software-collection.mjs` 支持传入两份 HTML 路径；构建直接使用已审核目录，不会实时抓取网站。

已修正：技嘉 Control Center 错指华为、TT 语音 Windows 入口错指 APK、测速网错指百度、酷我错指酷狗、逆水寒错指三角洲，以及 NVIDIA 两种异常路径后缀。历史驱动仅说明版本，不复述“推荐、稳定、通用”等未经验证的标签。

纠错对照可参照 [技嘉 Control Center](https://www.gigabyte.com/Consumer/Software/GIGABYTE-Control-Center/global/)、[TT 语音](https://www.52tt.com/)、[测速网](https://www.speedtest.cn/)、[酷我音乐](https://www.kuwo.cn/static/page/downloadPage/index.html)、[逆水寒](https://n.163.com/download/)。原链接和修正链接逐条记录在目录的 `corrections` 字段。

所有链接均经过协议和字段有效性检查，另对明显错链做了产品页面核对。未逐个下载或安装全部第三方软件，也未保证所有旧直链和网盘分享持续可用；界面使用“访问网站/下载文件/网盘下载”，不统一冒称“官方下载”。

## 验证

目录回归检查覆盖唯一条目、合法链接、来源、同名归并、错链修正、地区产品区分和历史驱动描述。宿主测试覆盖认证、目录查找、拒绝调用者 URL、浏览器错误传播。

Playwright 检查“进入软件合集 → 两个来源搜索 → 分类与空结果 → 打开入口/错误提示”，并检查 1380×860 深色及 1000×700 浅色窗口。Browser 插件未提供，采用项目现有 Playwright/Edge 工作流。真实 WebView2 检查确认内置目录、实际消息桥、入口解析、错误提示与锁定后移除页面；测试中的系统浏览器调用被替换为记录器，不会实际下载或执行软件。

最终统一安装包由“强化色彩主题并接入自动更新”聊天生成和发布，本功能不单独覆盖正式安装包或线上更新清单。
