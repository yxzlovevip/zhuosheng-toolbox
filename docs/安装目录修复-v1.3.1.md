# 安装目录修复 v1.3.1

2026-10-22。用户收到安装器启动阶段的“安装目录异常”，尚未进入安装位置选择界面。

实际安装记录为 `G:\Program Files\InternalToolbox`，旧版本 1.1.1。工具箱目录本身已由管理员和 SYSTEM 保护，但 `G:\Program Files` 向 Authenticated Users 开放 Modify，允许上级目录被替换。现有目录保护校验的拒绝有依据；缺陷是安装器启动即退出，没有可操作的修复入口。

v1.3.1 保留原位升级的目录保护要求。发现有效但上级权限不符合要求的旧安装后，显示“修复安装”，建议 Program Files 下可用的独立位置，并允许浏览选择其他合格位置。只有点击后才进行新位置安装，原有目录和文件保留，父目录权限不改变。建议位置已有文件时使用其他空的修复目录，不接管原文件。

修复时不复制旧可执行文件。用户本机主题、硬件缓存等个人设置仍沿用原 LocalAppData 位置；旧安装目录内额外文件留在原处，更新配置使用新包内置配置。新安装完成并登记成功后，才切换安装记录与快捷方式；失败继续使用现有安装事务回滚机制。自动升级参数不会跳过修复位置的手动选择。

验证：安装逻辑 22/22；安装器窗口 5/5，包含当前真实旧安装记录、首次安装目录选择、受保护旧位置保持原位、修复位置可选、--upgrade 修复模式不自动执行。测试没有执行实际安装、变更安装记录或调整本机目录权限。独立静态审查未发现阻止发布的重要问题。
