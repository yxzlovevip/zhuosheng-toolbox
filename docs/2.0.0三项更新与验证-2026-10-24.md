# 卓盛工具箱 2.0.0 三项更新与验证

日期：2026-10-24。交付范围为用户选定的用途搜索、下载来源和更新流程三项；同一安装包已按后续“直接更新线上版本”指令上线。线上验证见《线上发布-v2.0.0-2026-10-24》。

## 已完成

### 用途搜索

39 个工具均添加用途别名，前端与宿主搜索保持一致；原有分类、多词匹配、收藏和快捷打开规则保留。

修正开源工具目录重建时丢失用途别名的问题，重新打包后仍保留全部 39 项别名。搜索不会启动工具。

### 下载来源和核对状态

222 款软件的 307 个入口均显示来源类型与核对状态，主入口和“其他入口”一致处理；保持链接和工具数量，不用合集收录出处代替实际来源。

- 官网归类：218 个，按软件名限制的已知发布者域名表识别。
- 网盘：21 个，按完整域名边界识别。
- 第三方来源：2 个，明确的第三方下载或商店托管入口。
- 来源待核对：66 个，尚不能确认发布者，不猜测为官网。

其中本次实际打开核对的四个网页入口显示“入口已核对 · 2026-10-24”：7-Zip 作者主页、Everything 说明与下载页、Geek Uninstaller 产品主页。其余 303 个入口保持待核对且没有伪造核对日期。官网归类不意味着本轮逐个打开或下载了该域名下的文件。

微软扩展商店内的第三方扩展按第三方来源显示，不能因为页面托管在微软域名下就标为发布者官网。界面明确说明入口核对不代表下载文件已验证；打开入口仍只向宿主传软件及链接标识，不接收网页传入的任意地址。

### 更新流程

- 工具运行时允许下载并校验更新，下载期间也可以打开工具。
- 下载完成后，在更新页列出仍运行或正在打开的工具，提示先保存工作并退出；退出后列表自动消失。
- 工具未退出或运行状态暂时无法确认时，安装按钮不可用；轮询恢复后自动更新。
- 宿主在启动安装器之前重新检查真实进程组，返回具体工具名称；安装交接阶段阻止新工具启动。
- 保留下载取消、重试、锁定时取消下载、签名及文件校验、原路径升级与关闭工具箱时的进程树管理。

## 交付边界

本地验收之后，用户明确要求“直接更新线上版本”，同一哈希的安装包已上传并启用更新入口。没有修改用户已有安装登记，没有执行第三方维护或真实系统重装；线上发布不改变下述验收边界。
