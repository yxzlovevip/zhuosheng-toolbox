# 软件合集本地 Logo

2026-10-22，根据用户“把所有软件的 logo 也嵌入进去”的要求，将软件合集原来的名称首字占位替换为本地图片。

222 项全部有对应的 128×128 PNG，原始图标、官网标识和应用图标取自原 HTML、产品官网、官方源代码资源及 Simple Icons 品牌图标。资源导航与驱动下载使用所属站点/品牌标识。每张图片的来源 URL、文件路径和 SHA-256 记录在 `assets/software-logos.json`；特殊来源及底色在 `assets/software-logo-sources.json`。白色 Afterburner 标识使用深色底板保持可见，不修改品牌图形。

图片位于 `frontend/public/software-logos/`，由 Vite 公共资源复制到安装包的 `web/software-logos/`。运行时不请求原网站或第三方图标服务，目录离线浏览时仍显示全部图标。首屏以外的图片延迟解码，保留固定图框尺寸。

维护采集器 `scripts/collect-software-logos.mjs` 只在维护时使用，下载的数据会重新解码成 PNG，原网页/脚本不进入软件。日常构建不重新下载图标，先核对完整性和文件哈希。新增软件时也必须补齐其本地图标。

本轮特别核对了 GPU-Z、FurMark、Wallpaper Engine、DDU、Afterburner 和 Edge 扩展的实际应用图标，避免误用下载平台或厂商网站通用 favicon。Edge 扩展来源原条目名为“浏览器助手”，其商店实际名称为“zzpage-简约新标签页”，使用该商店记录中的图标。

验证包括：222 项目录映射与图片哈希、禁止外网请求后的全部图片解码、深浅主题和小窗口、真实 WebView2 解码，以及从真实安装 EXE 的资源展开后逐项核对图片。新包版本为 1.3.4，正式更新清单已于 2026-10-22 11:57（Asia/Shanghai）启用。

最终验证：目录与图标 2/2、完整前端 32/32、真实 WebView2 5/5、安装包 6/6 通过；291 个安装文件均与清单哈希匹配，其中 222 张软件图标与图标来源清单匹配。图标文件共 3,372,593 字节。安装包为 `dist/卓盛工具箱-安装-v1.3.4.exe`，大小 247,593,984 字节，SHA-256：`A33081881DA669209EC4A889A782AD9B68F2D6686E9AABF880DA8FF695EF6F85`。
