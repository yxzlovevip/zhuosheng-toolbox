# v1.4.3 安装包体积优化

用户选择全部工具随包附带，保留 8 个开源项目、14 个新增入口及原有工具。

原 v1.4.2 安装包为 1,386,136,064 字节，载荷约 2.79 GiB。主要体积来自 PowerToys（约 1,013 MiB）、ShareX（约 517 MiB）和各工具独立运行依赖。相同 SHA-256 文件的冗余原始数据约 392 MiB，但原始重复字节数不等于安装包可减少的字节数。

本轮使用 Stored ZIP + LZMA2 固实压缩，完整保留安装后文件；不跨项目强行共用版本不同的运行库，也不删除工具。最终安装包为 973,486,592 字节（928.4 MiB），减少 412,649,472 字节（393.5 MiB），缩小 29.8%。旧/新载荷全部 6493 个工具文件的 SHA-256 比较中，变化或缺失为 0。体积、SHA-256、实际安装结果记录在 `dist/build-result-v1.4.3.json` 和 `dist/卓盛工具箱-v1.4.3-验证结果.json`。

安装前检查安装盘可用空间，当前载荷约需 7 GiB（含临时压缩包和 ZIP）；提交注册前自动清理临时文件，清理失败由安装事务回滚。安装后的约 2.79 GiB 占用不会因安装包压缩而减少。

全部工具无需另行下载。首次安装机器若缺少 WebView2，仍沿用原有在线引导；本轮未额外捆绑体积较大的 WebView2 独立离线运行库。

验证已通过：真实压缩夹具 9 项、原安装 30 项、Framework UI 9 项、候选包首次隔离安装 9 项（6776 文件校验、39 工具、222 图标），以及 Windows .NET Framework 驱动调用实际 v1.4.2/v1.4.3 安装器引擎的隔离覆盖升级（168.2 秒，自定义更新设置、旧备份和临时清理均通过）。未更改当前用户安装记录或线上更新清单。完整杀毒扫描未完成，该版本仅为本地候选包。
