# 系统信息页

用户已确认设计并要求执行。面向现有 Windows 10/11 x64 工具箱，在软件内读取并展示本机信息。

- 左侧新增系统信息，包含硬件概览、BIOS、磁盘分区、机器码、显卡查询、全部设备六个页签。
- 按实例保留所有 CPU、内存、主板、显卡、磁盘、分区、网卡和 PnP 设备；缺少数据、拒绝访问和查询失败必须区分。
- BIOS 读取版本、日期、UEFI/Legacy、安全启动、虚拟化可用状态。厂商私有设置不可读取时明确说明，不提供修改功能。
- 磁盘显示硬盘与分区的归属、容量、盘符、文件系统和卷剩余容量；没有盘符的 EFI/恢复分区仍然展示。优先 Storage CIM，旧系统降级 Win32。
- 机器码读取 CPU ID、BIOS/主板/磁盘/内存序列号、内存料号、系统 UUID、网卡 MAC/IP/DHCP 信息。全部在本机处理，复制由用户触发，不记录查询值到日志。
- 显卡显示全部适配器和驱动；显存优先驱动 QWORD 字段，32 位 WMI 显存必须注明局限。按需读取 NVIDIA UUID、序列号、显存、温度与利用率；没有 nvidia-smi 时解释原因，AMD/Intel 通用信息仍可使用。
- 使用固定内嵌 PowerShell 查询脚本，不执行用户 BAT，不终止 WMI，不修改 BIOS、分区、硬件标识或配置，不发送网络请求。
- 查询异步运行，有整体超时、取消和防重复；锁定或关闭取消查询，禁止未登录调用。
- 沿用深浅主题，支持复制、刷新、筛选设备；加载、空数据、部分失败、整体失败都有可操作反馈。

验证包括：服务解析与错误测试、宿主鉴权/取消、浏览器完整交互和缩窄窗口、真实 Windows CIM 查询与真实 WebView2 渲染。当前设备以外的厂商固件和不同 GPU 驱动支持情况保留为兼容性限制。
