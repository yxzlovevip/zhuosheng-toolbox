## 目标与用户要求

将 F:\project\cz 中现有工具整理为一个中文 Windows 桌面软件，供朋友和内部人员使用。交付可安装的 EXE；主程序每次运行都要求管理员权限，每次启动必须输入口令 [本机访问口令，公开版省略] 后才能进入。界面优先让人看懂，逐项提供用途、操作步骤、影响和注意事项。具备自动更新能力，后续能接入其他项目。电脑信息查询功能本轮不做。

## 已核实的目录情况

- 原目录有 23 个文件，共 129,647,528 字节，约 123.64 MiB；没有现成的软件源码或 Git 仓库。
- 已读取脚本、注册表文件、EXE 版本信息和签名状态，并计算文件 SHA-256；没有执行任何原有工具。
- 部分 EXE 的版本描述与文件名不一致。文件名和版本描述只供初步分类，不能据此证明内部行为或运行结果。
- 当前环境有 .NET 桌面运行时，但没有 .NET SDK；实现时需准备项目专用构建环境。

## 产品结构

暂定名称为“内部维护工具箱”。左侧导航包括常用工具、网络工具、重装维护、系统设置、使用说明、软件更新。顶部展示搜索框、版本号和管理员状态。

工具列表展示中文名称、一句话用途、类别和影响提示。选中后在右侧显示详细说明，底部提供明确的启动按钮；避免双击列表就直接执行修改。

说明统一包含：这是什么、适用情况、操作前准备、操作步骤、可能影响、是否可能重启、如何判断结果、说明依据。对未实测的第三方工具显示“按文件名称整理，具体行为尚未验证”。不能编造工具内部按钮或保证操作成功。

工具被成功打开，只能显示“已启动”；不能显示“系统已修复”“设置已关闭”。退出码不能代替对系统结果的验证。工具由用户自行操作，不批量自动执行。

## 管理员权限与密码

通过 Windows 程序清单申请管理员权限。拒绝提升则不进入工具箱，不通过关闭 UAC 实现管理员运行。安装、工具目录和更新目标使用受管理员保护的位置。

每次启动先显示密码页，不保存自动登录。口令为用户指定的 [本机访问口令，公开版省略]；界面密码默认遮挡，支持回车提交和显示/隐藏。错误提示清楚，连续失败采用短暂等待，关闭重开仍需输入。验证在本地程序层完成，使用带盐口令校验值，不把明文写到可编辑的工具清单里。

这是共享口令入口，适合内部使用的简单门槛。它不能保证软件副本或被提取的第三方 EXE 只有指定人员能运行，也不具备账号吊销或设备授权能力。本轮不增加账号服务器。

## 技术与打包方向

推荐 Windows 原生桌面方案，使用 C# / WPF，工具目录与界面分离。另一个可行方案是 Tauri 桌面壳，但本轮主要是中文工具目录与本地启动，优先按 Windows 原生方案实现。若后续需要复用其他项目的页面，应通过独立集成接口评估。

交付一个安装 EXE，安装主程序、工具文件和更新辅助程序；主程序也为 EXE。计划自包含发布，使使用者无需手工配置开发环境。首版目标为 Windows 10/11 x64；未经过目标系统验收前不能声称完整兼容。

原工具封装后仍是独立第三方程序。没有要求它们运行静默参数，不修改它们的密码或内部界面。

## 工具启动与错误处理

工具清单只允许固定、经过打包审核的相对路径、固定启动方式和说明文本。启动前验证登录状态、管理员状态、路径位于受保护的工具目录、文件存在且 SHA-256 与发布清单一致；失败就显示原因，不搜索同名文件代替。

不允许清单提供任意命令，不把搜索内容拼成命令。重复点击需防抖；工具缺失、文件被拦截、启动失败分别给出可理解的提示。日志记录版本、工具标识、时间和启动错误，不记录口令。

对系统设置、重装和卸载类工具，执行前展示具体影响，由使用者确认启动；不提供一键执行所有维护工具的按钮。

## 自动更新

解锁后在后台自动检查更新，另提供手动检查按钮。展示当前版本、新版本、更新说明与下载进度；由用户选择安装并重启。联网失败不阻止使用现有工具，不能把检查失败显示成“已是最新版本”。

采用 HTTPS 更新地址及签名发布清单，客户端内置验签公钥；清单声明版本、下载地址、文件大小和 SHA-256。下载及验签失败均不执行安装。私钥只在发布端保存，不进入安装包、工具目录或客户端配置。

更新由受保护的辅助程序执行，确认主程序退出后再安装；保留失败日志，并通过预定的备份/恢复流程处理更新失败。第三方工具仍在运行时提示关闭，避免更新覆盖。

当前没有本项目的更新服务器地址。可以另设下载域名，也可以在现有官网上为本工具建立独立更新目录。代码和更新包准备完成不等于更新已上线；需要确定地址、上传新版并实测旧版更新后才能验收。

1. 管理员清单、密码错误/正确、未登录无法启动工具、关闭重开再次要求密码。
