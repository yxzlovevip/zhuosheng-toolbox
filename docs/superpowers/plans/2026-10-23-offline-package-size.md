# 完整离线安装包压缩 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 保留全部工具及文件的随包内置能力，缩小安装包，发布本地 v1.4.3 候选包。

**Architecture:** 继续使用原有 ZIP 安装引擎和路径检查、原子替换及回滚；将无压缩 ZIP 用官方 7zr 26.05 的 LZMA2 固实压缩封装。安装器内置 public-domain 7zr，先核对压缩包和解压器的 SHA-256，在安装根目录的临时子目录中，通过标准输出仅解出固定的 payload.zip，再校验完整 ZIP 的长度和 SHA-256。保留旧 ZIP 安装引擎，避免修改工具内容。

**Tech Stack:** .NET Framework 安装器、.NET 10 测试、PowerShell、官方 7zr 26.05。

**Spec:** 本文包含经用户选择的设计：完整离线、通过去重和压缩缩小；本轮先采用实测收益约 30% 的固实压缩，文件内容与目录布局不变。

## Global Constraints

- 全部 8 个开源项目及 14 个入口、现有工具保留，禁止改为按需下载。
- 沿用现有运行环境前提：首次机器缺少 WebView2 时原引导程序仍需联网，UI 用“全部工具内置”准确表述；不额外加入体积较大的 WebView2 独立离线运行库。
- 外层压缩只输出固定 ZIP；ZIP 内部仍执行原有路径、链接、重复路径和 4 GiB 展开限制。
- 主程序和解压器无需全局安装额外依赖；7zr 下载固定版本、固定 SHA-256，仅访问官方来源。
- 本轮不修改线上更新；临时解压文件始终清理，失败保留旧版本。
- 临时目录位于由安装 UI 预先保护的安装根目录下；解压器不从 PATH 查找，不使用 shell。
- 固实压缩需要额外约 2.8 GiB 临时 ZIP 空间，安装前检查空间并在界面说明。

## Review Focus

- 损坏压缩包/解压器/ZIP 校验失败时旧版本保持不变。
- 解压器失败、输出超长或不足时禁止安装，清理临时内容。
- 中文和空格路径、固定文件名参数不会被 shell 解析。
- 真正的旧版本覆盖安装和回滚仍工作。
- 最终安装的全部文件与构建清单完全一致；不得只以压缩成功作为完成。
