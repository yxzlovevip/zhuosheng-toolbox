## 服务器部署

服务器为 Alibaba Cloud Linux 3。原环境没有网站服务，本次从阿里云系统官方软件源安装 Nginx `1.24.0-3.0.1.2.al8.1`，由 systemd 的 `nginx` 服务管理并启用开机启动。这是系统 Nginx，配置位于 `/etc/nginx/`。

- 正式文件目录：`/var/www/cz-updates/releases/2.0.0/`。
- 下载站点配置：`/etc/nginx/conf.d/cz-download-test.conf`，监听 80，仅公开该版本 EXE、SHA256SUMS 和原签名清单。
- 私有操作记录：`/var/www/cz-updates/ops/`，目录权限 `0700`。
- 上传先进入唯一暂存目录，完成整包及签名校验后移动为版本目录；脚本拒绝覆盖已存在版本目录。
- 签名私钥未上传。SSH 使用受限临时副本，连接调用结束后移除临时副本。
- 本次安装事务临时允许系统包源提供 Nginx，原有包排除配置保持不变。
