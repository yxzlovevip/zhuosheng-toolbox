# 覆盖安装与自动建目录 v1.3.2

用户反馈：安装器将 G 盘已有安装当成必须换位置修复，手动填写不存在的 `D:\Program Files\InternalToolbox` 又被“上级文件夹不存在”阻断。用户要求自动检测旧安装，并让用户选择覆盖安装。

## 当前行为

- 从 64 位卸载注册记录读取位置，并验证工具箱标记。发现已有安装时直接展示原位置，默认“覆盖原安装（保留配置）”，另提供“安装到新位置”。
- 上级权限不符合要求时保留旧安装识别结果。对管理员/系统拥有且可修复的上级目录，列出路径，要求主动勾选同意才执行修复和覆盖；不自动接管其他账户目录或调整卷根。
- 新位置缺少中间目录时，点击安装后逐级创建并设置安全权限，选择路径不会提前创建目录。无关的非空目录仍拒绝覆盖。
- 推荐新位置只在切换到新位置时执行；推荐失败不会阻止打开覆盖安装界面。
- 失败提示保留；已有安装事务负责程序文件和注册失败回退，新流程另外恢复本次修改过的上级目录权限。
