# 安装目录选择（1.3.3）

首次安装提供路径输入框和“浏览”按钮。默认 `C:\Program Files\InternalToolbox`，也可选择其他本地固定 NTFS/ReFS 磁盘上的独立空文件夹，例如 `D:\内部工具箱`。

路径不能为卷根、Windows 目录、系统/个人资料根目录、链接路径或含有其他文件的文件夹。缺少的中间文件夹会在点击安装后自动创建，并设置管理员管理的权限；选择路径时不会提前创建。

安装器会检查已有上级目录的权限。如果上级目录由管理员或系统管理，但允许普通用户替换目录，会列出需要调整的路径，要求用户主动勾选同意后再安装。调整保留普通读写，移除普通用户针对这些目录的替换、接管和改权限能力；安装失败时尝试恢复原权限。不会自动调整整个磁盘根目录，或接管其他账户拥有的目录，这类位置需另选。

安装成功后，将位置记录在 HKLM 64 位卸载注册项 `InstallLocation`，并在根目录写入产品识别文件 `installation.id`。程序实际所在的 `app` 目录必须与注册记录吻合，自动更新才能使用该位置。

已安装时自动显示注册位置，默认选择“覆盖原安装（保留配置）”，路径只读，保留更新配置和上一版本备份。也可选择“安装到新位置”，此时可输入路径或浏览目录；原安装目录及文件保留，新安装完成后注册记录和开始菜单快捷方式指向新位置，不搬运旧程序文件。旧版本默认位置的安装记录仍可用于升级，升级后补写识别文件。

自动更新缓存、安装替换、开始菜单快捷方式和卸载器均使用所记录的位置。卸载依据每版安装清单及文件哈希删除未修改的工具箱文件，另行放入或已修改的文件保留；缺少清单的旧目录整体保留。升级清理上次备份时，如有保留文件，会将该目录改名为 `.preserved-随机标识`，留在安装根目录。

验证：25 项路径与安装事务测试、7 项成品安装器控件/隔离目录及权限检查、5 项成品资源检查、5 项隔离旧版覆盖更新检查。1.3.3 补测继承权限转换、隔离 NTFS 权限写入/还原以及实际安装失败分支的权限回退。控件测试读取实际安装记录，未覆盖本机安装或修改其注册记录；仅在 Program Files 下新建并清理唯一测试目录。真实旧安装上级目录权限调整、安装后启动与其他磁盘真实安装/卸载仍需目标环境验收。
