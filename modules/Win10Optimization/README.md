# Win10 优化系统封装

来源：`J:\装机系统必备工具箱\win10优化系统.bat`。`original.bat` 保留原始 18,541 字节，SHA-256 为 `CBCC92C1B91FA3ACB0B5C220D94E9D0D29D8FF9A76F1BF2D730364C572F6FA77`。

运行 `./modules/Win10Optimization/build.ps1` 生成 `工具/系统设置/Win10优化系统.exe`。重新生成后需更新 `assets/catalog.json` 中成品 SHA-256。主安装包沿现有工具目录规则收录成品，不收录原始 BAT。

封装复用浏览器 BAT 封装方式：声明管理员权限，在具有独立访问控制的随机临时目录展开原始字节，核对哈希并保持只读锁，等待首个 CMD 退出并传回退出码。拒绝包含原脚本无法正确处理的 CMD 特殊字符的临时目录。

仅传固定 `ELEV ::` 参数，兼容 NET FILE 检测失败并跳过冗余 mshta 自提权；不向 CMD 拼接调用者参数。原脚本还有独立的 CACLS 检测失败后自提权分支，可能通过 UAC 代理启动无法由封装等待的进程。因此一旦启动，封装保留私有临时目录中的 BAT（每次约 18 KB），不在首进程退出时删除。未能启动时才删除提取文件和空目录。这避免重新启动的脚本丢失；原脚本可能重复提权、部分失败的行为仍保留。

静态审查确认脚本会调整高性能电源方案、禁用自动睡眠和休眠、取消唤醒密码要求、修改桌面图标、关闭防火墙与 Defender 相关设置、禁用系统更新服务和策略、阻止升级助手、修改升级助手文件访问权限、删除相关计划任务和快捷方式，并结束和重启资源管理器。无自动备份或撤销。脚本含历史路径、重复自提权和未初始化的 `acguid`，个别命令可能失败；输出“任务结束”与退出码均不证明全部生效。仅按原文件名标为 Win10，未验证 Windows 11 兼容性。

`./modules/Win10Optimization/verify.ps1` 仅运行临时编译的无修改替身 BAT，验证固定参数、退出码，以及首进程退出后脱离等待的后续进程仍能读取 BAT。替身完成后测试自行清理其提取文件，随后静态校验成品内嵌原始字节。不会启动真实优化程序。
